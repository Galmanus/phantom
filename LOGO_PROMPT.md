# PHANTOM Logo Design Prompt

Use this prompt with AI image generators (Midjourney, DALL-E 3, Stable Diffusion) or human designers to create a logo for PHANTOM Protocol.

---

## Brand Overview

**Name:** PHANTOM  
**Tagline:** ZK Private Execution Layer for BTCFi on Starknet  
**Core Values:** Privacy, Cryptography, Bitcoin-native, Institutional-grade

---

## Design System (MANDATORY)

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| **Void** | `#0A0800` | Near-black background with amber undertone |
| **Surface** | `#110F04` | Card backgrounds |
| **Panel** | `#1A1600` | Elevated surfaces |
| **Border** | `#2A2510` | Subtle borders |
| **Amber** | `#F5A623` | Primary accent (Bitcoin orange) |
| **Amber Dim** | `#8B5E14` | Muted amber |
| **Amber Glow** | `rgba(245, 166, 35, 0.15)` | Glow effects |
| **ZK Green** | `#39FF14` | Proof verified, success states |
| **ZK Dim** | `#1A7A08` | Muted success |
| **Text Primary** | `#F5F0E8` | Parchment (not pure white) |
| **Text Secondary** | `#A89B80` | Muted text |
| **Text Muted** | `#5C5240` | Disabled states |

**IMPORTANT:** Amber = Bitcoin DNA. This is BTCFi-native, NOT Ethereum purple.

## Logo Concepts

### Concept 1: The Ghost Shield

- A stylized ghost silhouette merged with a shield shape
- The ghost should have "digital" or "circuit" patterns inside
- Use amber (#F5A623) for the main ghost/shield
- Add subtle ZK green (#39FF14) accents for "verified" feel
- The void color (#0A0800) as background

**Prompt:**
```
A minimalist logo for PHANTOM, a ZK privacy protocol for Bitcoin on Starknet. 
A sleek ghost silhouette merged with a shield, rendered in Bitcoin amber (#F5A623). 
The ghost has subtle circuit-board patterns inside. 
Subtle ZK green (#39FF14) glow effects around the edges. 
Dark void background (#0A0800). 
Clean, modern, cryptographic aesthetic. 
Professional, institutional-grade. 
Minimalist, vector style, high contrast.
```

### Concept 2: Poseidon Hash

- Abstract representation of the Poseidon2 hash function
- Fluid, wave-like forms representing the hash permutation
- Amber gradient from dark to bright
- A subtle "P" shape hidden in the negative space

**Prompt:**
```
Abstract logo for PHANTOM protocol. 
Fluid, wave-like forms representing cryptographic hash permutation (Poseidon2). 
Gradient from dark amber (#8B5E14) to bright Bitcoin amber (#F5A623). 
Subtle digital/circuit patterns integrated into the waves. 
ZK green (#39FF14) accent for "verified" state. 
Dark void background (#0A0800). 
Modern, crypto-native aesthetic. 
Minimalist, professional, sleek.
```

### Concept 3: The Invisible Vault

- A secure vault door that's partially "ghosted" or transparent
- Representing privacy and security
- Amber metallic finish on the visible parts
- The "invisible" parts fading into the void

**Prompt:**
```
A minimalist vault door logo for PHANTOM. 
Half-visible metallic vault in Bitcoin amber (#F5A623), 
half-fading into transparency (the "phantom" effect). 
Digital/lock elements integrated. 
ZK green (#39FF14) glow indicating "secure and verified". 
Dark void background (#0A0800). 
Professional, institutional, secure. 
Clean vector style, high contrast.
```

### Concept 4: Starknet Lightning

- A stylized lightning bolt (Starknet reference) that appears "ghostly" or transparent
- Circuit board patterns within the bolt
- Amber primary with ZK green accents

**Prompt:**
```
Logo for PHANTOM - a ZK privacy protocol on Starknet. 
A stylized lightning bolt (Starknet reference) that's partially transparent/ghostly. 
Bitcoin amber (#F5A623) with circuit-board patterns inside the bolt. 
ZK green (#39FF14) accents for cryptographic verification. 
Dark void background (#0A0800). 
Modern, tech-forward, crypto-native. 
Minimalist, professional, vector style.
```

## Style Guidelines

### Do:
- ✅ Use the specified color palette exactly
- ✅ Keep it minimalist and clean
- ✅ Reference cryptography/privacy themes
- ✅ Include Bitcoin/Starknet elements subtly
- ✅ Make it work in both light and dark contexts

### Don't:
- ❌ Use Ethereum purple/lilac colors
- ❌ Make it too complex or busy
- ❌ Use generic "crypto" aesthetics
- ❌偏离 Bitcoin 橙色主题 (Don't deviate from Bitcoin orange theme)

---

## Deliverables Needed

1. **Main Logo** - Full color, for light backgrounds
2. **Monochrome** - Single color (amber) for single-color printing
3. **Icon** - Square version for app icons, favicons
4. **Wordmark** - PHANTOM text next to logo
